02 / SYSTEM ARCHITECTURE

4 Core Components of
a Line Follower

The robot operates a continuous sense-decide-act feedback loop:

BRAIN

ESP32 Microcontroller

Executes control logic at high speeds, reading digital IR sensor inputs and generating PWM motor signals.

PERCEPTION

Dual IR Line Sensors

Infrared emitter/receiver pairs placed on the underside to detect light vs dark surface boundaries.

ACTUATION

TB6612FNG Driver

High-efficiency MOSFET dual H-Bridge driving two DC gearmotors with independent speed and direction.

POWER

LiPo / Battery Supply

Provides separate motor power (VM) and regulated logic voltage to the ESP32.

04 / SENSOR PRINCIPLE

Infrared Reflectance
Light vs Dark Detection

Understanding how IR reflectance sensors differentiate surface boundaries:

1. White Surface (Reflective)

White surfaces reflect infrared light back to the phototransistor photodiode.

DIGITAL OUTPUT

LOW (0V Signal)

Phototransistor conducts -> Signal pin drops LOW.

2. Black Line (Absorptive)

Black tape absorbs infrared light, preventing reflection to the receiver.

DIGITAL OUTPUT

HIGH (3.3V Signal)

Phototransistor off -> Internal pull-up pulls pin HIGH.

07 / CODE BREAKDOWN

Initialization &
Pin Mode Setup

Configuring GPIO directions & bringing driver out of standby in setup():

// setup() from line_follower/src/main.cpp

void setup() {
    Serial.begin(115200);
    pinMode(RC_MOTOR_STBY, OUTPUT);
    pinMode(RC_LEFT_PWM, OUTPUT);   pinMode(RC_LEFT_IN1, OUTPUT);   pinMode(RC_LEFT_IN2, OUTPUT);
    pinMode(RC_RIGHT_PWM, OUTPUT);  pinMode(RC_RIGHT_IN1, OUTPUT);  pinMode(RC_RIGHT_IN2, OUTPUT);
    pinMode(RC_IR_LEFT, INPUT);
    pinMode(RC_IR_RIGHT, INPUT);

    digitalWrite(RC_MOTOR_STBY, HIGH); // Enable TB6612FNG Driver
}

10 / HARDWARE TUNING

Speed Tuning &
Sensor Calibration

SPEED PARAMETER

#define SPEED 100

Controls maximum forward PWM duty cycle. Increase for speed, decrease if robot overshoots tight curves.

HEIGHT SENSITIVITY

Sensor Height (3mm – 5mm)

Keep IR modules 3mm to 5mm above the track surface for crisp high-contrast reflection signals.

POTENTIOMETER ADJUST

Threshold Trimmer

Adjust potentiometer on IR modules until onboard LED toggles sharply between tape and floor.

LOOP DELAY

Sampling Rate

A 100ms delay in loop() prevents Serial buffer overload while providing smooth steering evaluation.

11 / TROUBLESHOOTING

4 Common Line
Follower Pitfalls

ISSUE 1

Ambient Light Interference

Direct sunlight or bright overhead lights can blind IR receivers. Shield sensor array with a dark skirt.

ISSUE 2

Reversed Motor Direction

If robot spins in circles when going forward, swap motor terminals (IN1/IN2) or swap motor wire pairs.

ISSUE 3

Battery Voltage Sag

Weak batteries cause ESP32 micro-resets when motors start. Always use separate battery for VM rail.

ISSUE 4

STBY Pin Disconnected

If motors don't move at all, verify GPIO 23 (STBY) is driven HIGH in setup()!
