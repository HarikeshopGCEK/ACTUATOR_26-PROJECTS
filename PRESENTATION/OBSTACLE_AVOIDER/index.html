04 / SENSOR PRINCIPLE

HC-SR04 Ranging
Sonic Echo Principle

Computing target distance from sound propagation velocity (343 m/s):

  • Trigger Pulse Send 10µs HIGH pulse on RC_US_TRIG to fire 8-cycle 40kHz sonic burst.
  • Echo Measurement pulseIn(echoPin, HIGH) measures microsecond travel duration.
Distance (cm) =
Duration (µs) × 0.0343 2 
// Distance Measurement Helper Function

float measureDistance(int trigPin, int echoPin) {
    digitalWrite(trigPin, LOW);
    delayMicroseconds(2);
    digitalWrite(trigPin, HIGH);
    delayMicroseconds(10);
    digitalWrite(trigPin, LOW);

    long duration = pulseIn(echoPin, HIGH);
    return (duration * 0.0343) / 2; // Convert to cm
}

10 / HARDWARE TUNING

Threshold Tuning &
Sensor Calibration

DISTANCE THRESHOLD

20.0 cm Threshold

Provides optimal braking distance at 100 PWM motor speed. Increase threshold for faster speeds.

SENSOR ANGLE

15° Toe-Out Angle

Slightly angling left and right sensors outward expands forward field-of-view for corner detection.

TIMEOUT PROTECTION

pulseIn Timeout

If no reflection returns within 30ms, pulseIn returns 0 to prevent code freezing.

GPIO 35 INPUT ONLY

ESP32 Pin Constraint

GPIO 35 is an input-only pin without internal pull-ups. Ideal for HC-SR04 Echo output signal.

11 / TROUBLESHOOTING

4 Ultrasonic
Field Diagnostics

ISSUE 1

Soft Surface Absorption

Curtains or foam absorb 40kHz sound waves. Test obstacle avoidance against rigid surfaces.

ISSUE 2

Crosstalk & Interference

Triggering left and right sensors simultaneously can cause acoustic crosstalk. Space measurements out.

ISSUE 3

5V to 3.3V Echo Level Shift

HC-SR04 Echo pin outputs 5V. Use a resistor divider (1k/2k) when connecting Echo to ESP32 3.3V GPIOs.

ISSUE 4

Power Supply Noise

Motor electrical noise on VM rail can disrupt ultrasonic pulse timing. Add 100µF decoupling capacitor across VM/GND.
