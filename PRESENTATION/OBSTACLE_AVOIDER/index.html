02 / SYSTEM ARCHITECTURE

4 Core Modules of
an Obstacle Avoider

Real-time distance measurement drives autonomous path clearing:

BRAIN

ESP32 Microcontroller

Triggers 40kHz sonic pulses on GPIO 32, measures microsecond echo pulse widths on GPIO 35, and computes distance in centimeters.

PERCEPTION

HC-SR04 Ultrasonic Sensor

Single front-facing ultrasonic module provides non-contact distance sensing from 2cm to 400cm with 3mm precision.

ACTUATION

TB6612FNG Driver

Dual H-Bridge MOSFET driver controlling left and right DC motors to move forward or pivot away from obstacles.

POWER

Isolated LiPo Rail

Delivers clean logic power to ESP32 and high-current motor supply (VM) to avoid brownouts during directional changes.

04 / SENSOR PRINCIPLE

HC-SR04 Ranging
Sonic Echo Principle

Computing target distance from sound propagation velocity (343 m/s):

  • Trigger Pulse Send 10µs HIGH pulse on RC_TRIG to fire 8-cycle 40kHz sonic burst.
  • Echo Measurement pulseIn(RC_ECHO, HIGH) measures microsecond travel duration.
Distance (cm) =
Duration (µs) × 0.0343 2 
// Distance Measurement Helper Function

float measureDistance(int trigPin, int echoPin)
{
    digitalWrite(trigPin, LOW);
    delayMicroseconds(2);
    digitalWrite(trigPin, HIGH);
    delayMicroseconds(10);
    digitalWrite(trigPin, LOW);

    long duration = pulseIn(echoPin, HIGH);
    float distance = (duration * 0.0343) / 2; // Convert to cm
    return distance;
}

100 Duty Cycle

Provides stable motor traction and controlled pivot maneuverability during obstacle avoidance.

1000ms Delay

ESP32 Pin Constraint

GPIO 35 is an input-only pin without internal pull-ups, making it ideal for the HC-SR04 ECHO pulse.

11 / TROUBLESHOOTING

4 Ultrasonic
Field Diagnostics

ISSUE 1

Soft Surface Absorption

Fabric or foam surfaces absorb 40kHz acoustic waves. Test obstacle detection against hard, flat surfaces.

ISSUE 2

5V to 3.3V Echo Level Shift

HC-SR04 Echo pin outputs 5V. Use a resistor voltage divider (1k/2k) before feeding to ESP32 3.3V GPIO 35.

ISSUE 3

Motor Supply Noise

DC motor electrical noise on VM rail can trigger false sonar readings. Add a 100µF decoupling capacitor across VM/GND.

ISSUE 4

Timeout Protection

If no echo reflection returns, pulseIn times out to avoid blocking execution indefinitely.
