06 / CODE BREAKDOWN

Directional Motor
Driving Functions

Core motor driving helpers from web_controlled_car/src/main.cpp:

// Left & Right Motor Controls with Speed Signed Polarity

void leftMotor(int speed) {
    if (speed > 0)       { digitalWrite(RC_LEFT_IN1, HIGH); digitalWrite(RC_LEFT_IN2, LOW); }
    else if (speed < 0)  { digitalWrite(RC_LEFT_IN1, LOW);  digitalWrite(RC_LEFT_IN2, HIGH); }
    else                 { digitalWrite(RC_LEFT_IN1, LOW);  digitalWrite(RC_LEFT_IN2, LOW); }
    analogWrite(RC_LEFT_PWM, abs(speed));
}

void forward()  { leftMotor(motorSpeed);  rightMotor(motorSpeed); }
void backward() { leftMotor(-motorSpeed); rightMotor(-motorSpeed); }
void left()     { leftMotor(-motorSpeed); rightMotor(motorSpeed); }
void right()    { leftMotor(motorSpeed);  rightMotor(-motorSpeed); }
void stopCar()  { leftMotor(0);           rightMotor(0); }
07 / CODE BREAKDOWN

Asynchronous HTTP
Request Handlers

Parsing incoming URL query arguments in handleMove() and handleSpeed():

// HTTP Endpoint Handlers

void handleMove() {
    String direction = server.arg("dir");
    if (direction == "forward")       forward();
    else if (direction == "backward") backward();
    else if (direction == "left")     left();
    else if (direction == "right")    right();
    else                              stopCar();

    server.send(200, "text/plain", "OK");
}

void handleSpeed() {
    if (server.hasArg("value")) {
        motorSpeed = constrain(server.arg("value").toInt(), 0, 255);
    }
    server.send(200, "text/plain", "OK");
}
08 / CODE BREAKDOWN

Wi-Fi SoftAP Setup &
Server Launch

Creating standalone Access Point & binding HTTP routes in setup():

// setup() from web_controlled_car/src/main.cpp

void setup() {
    Serial.begin(115200);
    // Pin Modes & STBY HIGH...
    digitalWrite(RC_MOTOR_STBY, HIGH);
    stopCar();

    WiFi.mode(WIFI_AP);
    WiFi.softAP(SSID, PASSWORD);
    Serial.print("AP IP: "); Serial.println(WiFi.softAPIP());

    server.on("/", handleRoot);
    server.on("/move", handleMove);
    server.on("/speed", handleSpeed);
    server.begin();
}
09 / CODE BREAKDOWN

Zero-Delay Execution
server.handleClient()

Main loop execution remains 100% non-blocking:

// Non-Blocking Loop Execution

void loop() {
    server.handleClient(); // Process incoming HTTP client requests immediately
}
GOLDEN RULE

Never Call delay() in a WebServer Loop!

Calling delay() inside loop() causes Wi-Fi packet drops and severe control latency on mobile touch dashboards.

11 / TROUBLESHOOTING

4 Web Car
Field Diagnostics

ISSUE 1

Wi-Fi Disconnects

ESP32 SoftAP antenna is sensitive to battery voltage sags. Ensure clean 5V/3.3V logic supply to ESP32 board.

ISSUE 2

Captive Portal Popup

Some smartphones expect internet access on Wi-Fi. Disable "Switch to Mobile Data" setting on phone.

ISSUE 3

Motor Command Latency

If car continues driving after releasing button, check that ontouchend="stop()" is registered on touch elements.

ISSUE 4

Stall at Low Speed

If motors hum at low speed slider settings, increase minimum slider threshold to 60 PWM.
