04 / complete signal reference

What each group
is good for.

POWER

VIN · 3V3 · GND

VIN accepts regulated 5 V through the board regulator. 3V3 is the regulated output. Connect grounds together before testing.

DIGITAL I/O

GPIO 0–33

General-purpose digital pins. Most support input, output, interrupts, and PWM. GPIO 34–39 are input-only.

ANALOG

ADC1: 32–39

Use ADC1 for analog sensors when Wi-Fi is active. ADC2 conflicts with Wi-Fi and is less dependable for that use.

SPECIAL

DAC · TOUCH · RTC

DAC output: GPIO25/26. Capacitive touch: GPIO0, 2, 4, 12–15, 27, 32, 33. RTC GPIOs support low-power wake.

06 / pin map at a glance

A quick-reference
cheat sheet.

SAFE STARTERS

GPIO 16, 17, 18, 19, 21, 22, 23, 25, 26, 27, 32, 33
Good general choices after checking your peripheral requirements.

INPUT ONLY

GPIO 34, 35, 36 / VP, 39 / VN
Read sensors here. They cannot drive an LED, relay, or motor.

FLASH RESERVED

GPIO 6–11
Connected to the module's SPI flash. Do not use them as breakout pins.

BOOT SENSITIVE

GPIO 0, 2, 5, 12, 15
External pull-ups or pull-downs can stop the board from booting.

07 / power and protection

Three rules
before power-up.

  • Use 3.3 V logicESP32 GPIO is not 5 V tolerant. Level-shift 5 V sensor signals.
  • Share the groundEvery external module needs a common GND reference with the ESP32.
  • Feed motors separatelyMotor noise and current spikes belong on their own supply, with a driver between.
CHECK THIS FIRST

Never connect 5 V directly to a GPIO.

Power the board through USB, VIN, or a clean regulated 5 V source. Confirm polarity and current capacity before attaching a battery.

08 / from code to motion

Sense.
Decide. Act.

A reliable embedded project keeps the loop simple: collect a signal, make a decision, produce a visible result.

GPIO → peripheral → logic → output

// read, decide, respond
const distance = readSensor();
if (distance < SAFE_LIMIT) {
  stopMotors();
  signalWarning();
} else {
  driveForward();
}
